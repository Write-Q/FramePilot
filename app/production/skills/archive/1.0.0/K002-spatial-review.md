# K002 · 空间与连续性自检 · 1.0.0

在提交规划前检查同场相邻镜头：人物画面左右、视线、运动方向、道具持有人、服装和动作起止状态；不能凭空让道具回到原持有人。原剧本已有冲突只能提醒，不自动添加取回/移动事件。

正反打保持可理解的空间关系。轴线和视线信息不足时标记待确认，不声称通过180度检查。有意跨轴、重新定场或时间跳跃可用，但在 continuity_notes 说明镜头内过渡或创作理由。不同场次、不同人物关注点不要求所有 state_start 与上镜 state_end 文字完全相同。

动作节拍和台词密度需给表演留余地，不能把固定字速当成硬标准。审核的是计划，不是已生成影像；不得声称看到了实际末帧、验证角色一致或证明物理正确。需要人工核对的地方写入 continuity_notes/creative_notes。

这是与 K001 组合的单次调用自检指令，不是独立模型裁判。程序随后只做有限结构/启发式检查，最终由用户决定。
