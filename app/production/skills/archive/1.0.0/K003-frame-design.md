# K003 · 静态帧与运动意图 · 1.0.0

每个镜头输出 frame_prompts.first。描述镜头开始瞬间的主体、姿态、人物相对位置、道具持有人、景别、构图与照明；动作尚未完成时不能将完成态提前画入首帧。例如交接钥匙前，首帧钥匙还在递出者手中，尾帧才在接收者手中。

只有表演或状态变化需要时才填写 key/last：key 是最有信息的瞬间，last 与 state_end 对齐。一个镜头可以有多个画格，不把三个时刻拼成一张三联图。静态帧各描述一个瞬间，不加入“然后/接着”串联动作。image_prompt 可作为静态主画面候选，但不能和首帧互相矛盾。

video_prompt 描述从起始态到结束态的主体动作、时间变化与镜头运动；不把首尾两个矛盾状态混为同时成立。它是供应商中立的运动意图，尚未编译成具体模型请求。不要填写伪造参考图编号、图片URL、模型专属负面词或未验证参数。填写尾帧文字不代表后续模型支持尾帧输入。

不生成图片或视频，不声称已验证画面效果。资产未定的信息留在 creative_notes 待人工确认。
