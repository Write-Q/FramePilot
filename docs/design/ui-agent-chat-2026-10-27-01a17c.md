# Agent 对话框设计预览

用户要求在柔和创作工作室方案中采用主流 Agent 对话框样式。本轮调整为常见对话结构，延续已选配色；并非对任何具体产品的完整复刻。

- 用户消息右对齐浅灰气泡，助手回复左对齐开放正文与列表；修改建议独立预览，保留人工采用和保存。
- 桌面助手栏 300px，中等屏幕 240px，手机面板切换保留草稿。
- 独立圆角输入框、引用当前镜头、圆形发送按钮；空输入/纯空白禁用，Enter 发送、Shift+Enter 换行，IME 输入期间不误发。
- 引用作为消息上下文显示并可移除；没有增加文件上传、假模型配置或虚构工具执行状态。

同目录 `ui-agent-chat-2026-10-27-01a17c.html` 可打开查看；当前聊天中的交互预览为同一设计。所有内容均为本地示例，不调用模型、不写真实项目，不包含新增图片。重载会重置内存草稿。

验证：脚本语法通过，1024/736/390/320 四宽度无横向溢出；十四组交互检查通过，浏览器 pageerror 为 0；已检查桌面及手机助手面板截图。详细结果见同前缀 verification.json，来源足迹见 [Agent 对话框试作](../devlog/2026-10-27-agent-chat-style-01a17c.md)。

尚未改动 app/static 或生产对话服务，等待用户审阅后确定正式适配。
