# 视频审核第一版实施

1. 真实抽帧：成功视频固定checksum，受控子进程读取，最多12帧、640像素宽高边界，保存实际时间戳，单独媒体文件，不把采样当全视频语义审核。
2. 独立0010报告/人工记录表，复用视频任务归属；报告含技术已解码信息、实际/计划时长和画幅、帧证据。默认内容状态待人工，记录人工时间区间发现及reviewed/needs_revision结论，不自动批准视频或改上游。
3. API创建/列表报告、读证据帧、提交人工记录；版本/项目/文件校验与幂等保护。先TDD后实现。
4. 工作台报告按钮、帧证据、点击定位原视频、人工备注和结论。旧版本只读，未配置视觉模型不展示自动内容审核成功。
5. 隔离数据库、真实编码视频、浏览器回归及review检查；备份演练后启用新表，阶段提交推送。模型语义审核和后期剪辑保留后续。
