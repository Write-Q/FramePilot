# 单镜视频运行时

目标：将现有视频输入和VideoAdapter契约接入持久化任务、提交/查询、候选选用；无真实供应商时以注入适配器测试，不开放虚假可用选项。

1. 新增0009及独立video_schema，任务绑定同项目同版本首帧、分镜、配置和提示词，状态及终态不可变，独立选用历史。
2. 实现VideoRuntime和契约；create检查实际注册执行器与能力，submit前校验来源，提交成功先保存external_id，poll仅按外部ID查询。并发领取使用数据库锁，未知状态不重复提交。
3. 注册模型metadata、API及独立视频worker，默认适配器为空；接口返回明确未配置状态，网页只提供可用性与历史，无供应商不可提交。
4. 视频输出先经过实际验证的文件存储再可选用；未配置验证器不能将任意字节写成成功候选。测试明确注入替身，不能宣称真实可解码或模型质量。
5. 先失败测试再实现，验证幂等、外部ID持久化、提交超时、查询恢复、晚到结果、版本隔离。回归并更新足迹/功能说明。0009先在隔离库验证，业务库迁移另做备份与演练。
