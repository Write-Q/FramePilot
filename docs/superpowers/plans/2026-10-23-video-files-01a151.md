# 视频文件与播放器实施

1. 新增VideoFiles：PyAV子进程实际解码全部流，限制字节/像素/帧数/处理时间，拒绝远程/播放列表协议与多图假视频，生成width/height/duration_ms；UUID标识不可覆盖存储。
2. 默认接入VideoRuntime/API同一持久化目录；输出读取按项目+方案+任务归属定位成功结果，通过FileResponse支持Range，不接受客户端路径。核对文件大小/checksum，响应nosniff。
3. 视频历史展示播放器、实际宽高/时长与计划差异、同版本人工选用、查询恢复/取消/未知处理；具体服务仍为空，不出现假可用生成选项。
4. 真实编码短片生成测试、解码和损坏/越界测试、隔离PG提交poll成功文件读取与Range测试、浏览器播放和选用测试，保持模型生成质量证据独立。
5. 无新增业务schema；迁移仍0009。记录依赖、环境、实际测试结果和未完成项。
