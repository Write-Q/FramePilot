# 本地后期成片第一版

从分镜工作台的“后期成片”进入 `/editing?project=项目ID&board=分镜ID`。来源必须是当前已确认分镜，镜头视频可来自成功验证并人工选用的生成候选，也可从本地素材库明确加入。真实视频供应商尚未选定；当前完整链路通过测试环境的真实本地编码素材验证。

支持镜头排序与裁切、原声增益、WAV配音/音乐轨、进入时间和循环、中文字幕、横屏/竖屏/方形画幅。保存创建不可覆盖时间线版本；旧版只读。新导出必须与当前来源及选片一致。渲染成功和人工验收分开记录。

运行前安装锁定依赖，并备份数据库、演练升级后显式执行迁移至 `0012_local_clips`。应用不会自动迁移。独立启动本地渲染进程：

```powershell
.venv/Scripts/python.exe -m scripts.editing_worker
# 仅处理最多一个排队任务：
.venv/Scripts/python.exe -m scripts.editing_worker --once
```

页面提交导出只会入队。worker使用本地FFmpeg生成24fps H264/AAC MP4，经实际解码及校验后保存；可播放、Range下载和记录验收意见。运行中断的任务保留原状态，核对后标记结果未知；不会在重启时自动重新渲染。网络响应丢失后页面保留原幂等请求重试。

限制：1至30个片段，单段至少200ms，总长不超过600秒；最多100条字幕、4条外部音轨；单WAV不超过20MiB/600秒，单成片不超过256MiB；本地渲染超时明确失败。需要含libass、libx264和AAC的FFmpeg及可用中文字体；当前查找系统微软雅黑或Noto Sans CJK。素材缺失、校验变化或字体缺失不会静默忽略。

本版为人工配置、确定性合成。自动配音、自动语义剪辑、复杂转场和精细调色、真实模型效果评估仍需后续实现或联调。本地视频上传独立存储，明确标为本地导入，不创建模型配置或虚构生成任务。上传不自动加入时间线；可先预览，再点击“加入时间线”。同一页面上传响应丢失后用原文件、原幂等键重试；刷新页面后应先核对素材库再决定是否新上传。每项目最多100份本地视频，单份不超过256MiB/600秒，仅接受MP4 H.264或WebM VP8/VP9。

业务库0012升级、真实浏览器对真实导出播放/下载/验收、450项全量回归已完成；证据见[本轮验收](devlog/2026-10-23-pre-model-acceptance-01a151.md)。本地视频入口及0012业务升级已完成；最终回归和20项独立页面测试证据见验收足迹。画面实际时长用于裁切，较长原声音轨在画面结束时截断；延迟原声保留相对画面的偏移。

画面第一帧定义时间线的素材零点。渲染显式保留输入时间戳，并将画面及原声对齐同一裁切起点，适用于非零容器起点、音频先于画面和延迟原声。原始导入文件与导出文件校验和均留存，历史不回写；修改分镜不会将旧本地素材自动绑定到新版本。

HTTP入口在 `/api/production/projects/{project}/storyboards/{board}/editing` 下：

| 接口 | 参数/行为 |
| --- | --- |
| POST `/local-clips` | raw视频正文，Content-Type为video/mp4或video/webm；X-Expected-Version为已确认分镜版本，X-Idempotency-Key为16至64位请求键，X-Filename为encodeURIComponent后的展示名 |
| GET `/local-clips` | 当前及历史素材，applicable明确是否能用于当前分镜 |
| GET `/local-clips/{id}/media` | 核验归属与checksum后的Range读取 |
| POST `/timeline` | clips[].run_id兼容生成任务ID或local_前缀本地资产ID；本地来源写入固定manifest，客户端不提交文件路径 |
