## 核心对象不能混为一谈

| 对象 | 它表示什么 | 不能替代什么 |
| --- | --- | --- |
| 剧本场戏 | 同一叙事时空中的连续事件 | 自动检测到的视觉切点 |
| 分镜镜头 | 叙事与摄影表达单元 | 单张分镜画格或唯一视频文件 |
| 画格/关键帧 | 某个时刻的画面意图或图像 | 完整动作与时间连续性 |
| 生成单元 | 供应商一次请求的制作范围，可能对应一个或多个镜头 | 永久固定的剪辑片段 |
| 媒体候选 | 某次生成/上传得到的具体文件 | 已采用版本或正式成片 |
| 剪辑片段 | 在时间线上使用素材的某个区间 | 原始素材本身 |
| 审核问题 | 对具体版本和区间的待确认判断 | 用户授权或绝对事实 |
| 来源凭证 | 创建/修改历史的记录与签名 | 版权、真实性或内容质量的自动证明 |

## 与现有实现的关系

现有编剧第一版已提交5534950。制作首段API具备配置版本、手工分镜与确认；自动分镜、资产服务、真实生成、视频审核、worker、剪辑仍未接通。本文对下游的描述是目标边界，不反向宣称功能已经存在。既有数据库关系不等于所有服务都实现。
