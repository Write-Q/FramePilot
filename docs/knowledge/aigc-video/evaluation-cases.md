# 评测案例种子

下列24项是**案例设计，尚未执行**；不是标注视频集、模型得分或测试通过记录。每项都需要后续补充确切输入、素材、人工标签、版本和证据。不要将这些场景直接计为24个已验证能力。

| 编号 | 场景 | 输入条件 | 预期判定/行为 | 验证方式 |
| --- | --- | --- | --- | --- |
| E001 | 完整剧情覆盖 | 一个含发现、交接、开门的短剧本 | 分镜覆盖关键事件，不能只出现情绪反应而遗漏开门 | 语义/人工 |
| E002 | 创作补充边界 | 只允许细化表演、不允许新增对白 | 新增对白或动机标为待确认，不能写成原文事实 | 来源/语义 |
| E003 | 对话反打 | 人物A在左向右看，B在右向左看 | 相邻镜可理解其对话对象，不能无故翻转左右 | 视觉/人工 |
| E004 | 合理跨轴 | 一个连续移动镜头明确跨越互动轴线 | 不机械报告跳轴错误，说明新空间基准 | 视觉/人工 |
| E005 | 首帧提前完成 | 镜头动作是递钥匙，首帧却已由对方持有 | 指出起始/完成态冲突，或保留用户明确指定的例外 | 语义/视觉 |
| E006 | 动作与对白过密 | 短镜头同时含多步接触动作及长对白 | 提出拆分或延长建议；不得靠删原台词假装满足时长 | 计时/人工 |
| E007 | 道具与身份状态 | 同一人物换装/受伤发生在明确剧情节点 | 绑定相应状态版本，不将两种状态当两个人物 | 版本/视觉 |
| E008 | 提示词规则不兼容 | 把要求正向表达的模型切换到支持负面字段的模型 | 按确切模式编译，不复制前一模型的HTTP字段 | 契约/真实接口 |
| E009 | 退役与不可读文档 | 用户指定历史Sora方案，另一个模型官方页不可读 | 分别报告退役和未知，不视作可直接执行能力 | 文档/确定性 |
| E010 | 本地资源不足 | 目标权重/精度超过实测资源容量 | 明确失败和所用环境，不能宣称仓库存在即可运行 | 真实硬件 |
| E011 | 工作流结果归属 | 两个ComfyUI任务同时返回不同素材 | 用prompt ID和结果清单正确关联，不能串项目 | 工具/集成 |
| E012 | 提交结果未知 | 请求已发出但未收到外部ID后超时 | 保留UNKNOWN和请求指纹，按供应商证据核对而非盲重提 | 故障注入 |
| E013 | 重启与重复结果 | 已知外部ID、重启、重复回调或查询成功 | 恢复同一任务并去重，不能再次扣费或追加重复采用 | 故障注入 |
| E014 | 短暂视觉缺陷 | 缺陷发生在均匀采样帧之间的短区间 | 报告采样覆盖不足；加密采样或人工检查，不能伪称全程通过 | 真实/合成媒体 |
| E015 | 审核误报 | 有意时空跳切、道具从画外被拿起 | 要求证据和上下文，允许驳回，不能自动重生成 | 语义/人工 |
| E016 | 旁白与口型 | 画外音持续，画内人物应保持闭口 | 检查说话归属与实际视频，不只验证对白文本一致 | 音画/人工 |
| E017 | 字幕对齐误差 | 中英混合语句、停顿、两人重叠发言 | 保留转录/对齐不确定区间，字幕可修订且不截词 | 音频/人工 |
| E018 | 局部剪辑修改 | 第三片段裁短，其他素材保持采用版本 | 只修改相应时间线并重新渲染，不重新生成全部镜头 | 确定性/集成 |
| E019 | 精确裁切与时间基 | 非关键帧切点、可变帧率或不同帧率素材 | 选择合适处理方式并测量输出，不能只比名义秒数 | 真实媒体 |
| E020 | 混合素材拼接 | 不同分辨率、编码、音轨存在/缺失的片段 | 统一必要属性，保证输出可解码、声音与画面对齐 | 真实媒体 |
| E021 | 数字推近与新视角 | 用户要环绕看到人物背面，原视频只有正面 | 说明缺失视角，提出生成/三维方案，不能用缩放冒充 | 能力/人工 |
| E022 | 分数与叙事分离 | 画质高但关键线索遗漏的生成片段 | 分项报告技术好、叙事不合格，不能仅用总分宣布完成 | 评测/人工 |
| E023 | 交付目标差异 | 广播与网络平台要求不同的同一份音画素材 | 为每种交付记录目标及测量，不套全局固定响度/色彩 | 标准/工具 |
| E024 | 链接过期与追溯 | 供应商下载链接过期或签名参考链接变化 | 用稳定素材身份和checksum追溯，按能力重新取链而非重新生成 | 存储/集成 |

## 运行记录要求

每次试验保留case_id、数据集版本、技能/提示词版本、模型配置与快照、原始请求响应、采用素材ID/checksum、采样方案、人工结论、程序检查、模型结论、耗时、已知费用/估算及未知项。

模拟HTTP/队列测试只能证明程序行为，不计入真实模型成片效果。真实与合成缺陷视频分开统计；缺少真实素材的用例明确标记未执行。失败、过滤、超时和UNKNOWN保留在原始结果，不通过补样本掩盖。

自动分数与人工评价并列报告；审核器统计误报和漏报，不能只记录阻断次数。候选素材采用、问题解决与用户确认分别计数。调参用开发集，最终评估使用另行冻结的留出集；本文件只作开发种子，不提前宣称独立评测。
