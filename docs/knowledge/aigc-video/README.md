## 全链路参考结构

创作简报与资料事实 → 剧本及确认 → 导演/场戏 → 分镜与空间连续性 → 资产与静态帧 → 模型能力/提示词编译 → 生成任务与素材 → 技术/语义审核 → 剪辑/声音/字幕 → 成片验收与交付。预算、版本、授权、来源链贯穿每一步。

分镜与后期是不同业务模块，媒体、模型配置和任务设施共享。专业教学说明“为什么这样表达”，参考项目说明“如何组织实现”，官方API说明“当前怎样调用”，评测与实际作品说明“效果是否成立”。四类证据不能互相替代。

## 本地优先，不反复关键词搜索

先按问题路线读本地结论，再按来源ID和locator直接打开原始文件/章节。稳定概念可只依本地摘要；涉及当前模型、API、费用、地区、许可时，仍需在保存的官方入口核实。精确来源失效或覆盖不足时才广域搜索。命令示例在maintenance.md。

每个来源保留作者/机构、类型、主题、精确URL与位置、版本、核对日期、阅读程度、可访问性、生命周期、应用建议及限制。固定Toonflow/Jellyfish具体提交；浮动仓库在实际依赖前另锁版本。所有摘要是自写整理，未镜像整站或复制完整课程。
