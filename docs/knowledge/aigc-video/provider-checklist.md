## 能力证据必须逐字段记录

| 组别 | 必查字段 |
| --- | --- |
| 身份 | provider、endpoint/base_url、API版本、区域、model_id/快照、mode |
| 输入 | text/image/video/audio是否支持、角色、顺序、数量、尺寸、编码、时长、文件大小 |
| 传输 | URL/base64/upload_id、访问有效期、下载权限、媒体是否真正传入 |
| 输出 | 时长离散值/范围、画幅、分辨率、帧率、编码、音频、文件/链接有效期 |
| 控制 | seed语义、首尾帧、参考图、摄像机、声音/字幕、扩展/编辑支持 |
| 执行 | submit/query/list/webhook/cancel/download、外部ID、状态及结果未知处理 |
| 费用 | 计费单位、失败/取消计费、估算来源及日期、预算与实际账单差异 |
| 限制 | 账户资格、地域、并发、速率、内容/肖像限制和官方退役状态 |
| 证据 | document_url、section、checked_at、declared/documented/runtime_verified、原始响应与失败 |

“用户声明”“文档支持”“目标账户实测”分别记录；未核实填unknown，不能填false假装不支持，也不能填true假装已测。真实模型返回的约数时长与下载后的ffprobe值分别保存。

## 公共层与适配器的边界

公共层表达制作意图、资产角色、任务来源、预算和状态；适配器负责供应商字段、鉴权、输入编码、错误及任务状态映射。不能把所有视频端点强行改成聊天接口；也不能让未经校验的扩展参数覆盖host、headers、路径或认证。

公开文档示例只证明写法来源，不能证明任务已执行。连接测试、最小真实任务和画面质量测试是三个不同验收层；可能计费的探针需在实际授权范围内执行。本次只建库，没有运行这些探针。
