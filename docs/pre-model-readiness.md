# 真实模型接入前验收范围

本页对应分镜、媒体制作、视频检查与后期模块。完成这里的工程检查，意味着可以开始供应商适配和真实效果评测，不意味着模型生成质量已经合格。

| 环节 | 工程能力 | 真实模型边界 |
| --- | --- | --- |
| 文字分镜 | 固定已确认剧本、规划/编辑/版本/确认、规则及独立文字审核、型号/思考等级与通用兼容/DeepSeek配置 | 已有文字专门评测见对应QA记录；不能据此推定视频质量 |
| 静态帧 | 单图base64通用接口、独立任务领取、来源/提示词/配置固定、真实解码、预览及人工选用 | 供应商/中转平台、图像编辑和模型专用参数待选定后核对 |
| 视频任务 | submit/poll协议、外部ID持久化、只恢复查询、未知结果不自动重付费、真实解码/播放/选用 | 尚未选择供应商，尚无具体可调用视频HTTP适配器 |
| 视频检查 | 技术报告、真实抽帧证据、时间段问题及人工结论历史 | 自动语义、角色一致性、台词/口型审核需要多模态模型或ASR后实测 |
| 后期 | 版本化时间线、裁切排序、原声/本地WAV/字幕、固定画幅与FFmpeg导出、播放/下载/人工验收 | 模型不参与确定性合成；TTS/ASR和自动剪辑策略不属于当前已接通能力 |
| 本地视频入口 | 已实现独立本地资产、明确加入时间线、原请求恢复和来源标记 | 不得伪装生成候选或虚构模型配置 |

工程验收要同时满足：测试隔离数据库和回归通过；迁移有备份、随机库恢复演练、旧表指纹与schema检查；真实浏览器实际播放/下载；关键异常有明确恢复且不产生重复外部请求；输入/输出和来源版本可追溯。

选定真实供应商后才进入：核对官方协议/账户区域/费用/模式/限额；填密钥环境变量、型号和已验证参数；最小单图/单镜调用，再做多镜角色一致性、时长、运动、声音等效果案例。采用资料库固定入口[供应商核对表](knowledge/aigc-video/provider-checklist.md)与[评测案例](knowledge/aigc-video/evaluation-cases.md)。不要以模拟响应或能解码文件代替真实效果评测。

本轮计划内工程闭环已验收：450项完整pytest、20项独立Node、两种来源真实浏览器流程，以及0011/0012业务升级和备份恢复演练通过。证据及边界以[本轮足迹](devlog/2026-10-23-pre-model-acceptance-01a151.md)为准。业务备份与媒体保留在本机忽略目录，不上传GitHub；数据库与data/media、data/video、data/audio应一起备份。
