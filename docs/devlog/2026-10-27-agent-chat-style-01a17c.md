# Agent 对话框样式试作

## 用户需求与边界
- 用户要求 AI 对话框采用主流 Agent 的样式。本轮在已授权的柔和创作工作室设计预览上局部调整，不修改生产对话服务。
- 保留 Craft 柔和浅色与 FLORA/Linear 精细工具质感；本轮无图片生成、无项目模型调用。
- 独立新预览 `framepilot-agent-chat.html`，保留上一版预览和归档不覆盖。

## 实际改动
- 桌面助手栏由 230px 调整至 300px；中等屏幕 240px，手机延续工作区/助手面板切换。
- 用户消息右对齐浅灰气泡，助手正文左对齐并用短段落/列表呈现；修改建议作为独立变更预览块，不模拟已执行。
- 输入框采用独立圆角容器、下方上下文工具与圆形发送按钮；输入为空时发送禁用，Enter 发送、Shift+Enter 换行，保护中文 IME 组合输入。
- 本地支持引用当前镜头与移除引用，引用随示例消息显示；所有内容以 textContent 呈现，未接入文件上传、模型选择或伪造思考状态。
- 以上交互仅本地演示，重载重置，不声称真实项目已保存或 AI 已回复。
