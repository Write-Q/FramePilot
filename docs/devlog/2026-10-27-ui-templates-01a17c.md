- 用户将所指的五个板块用于交互及 UI 设计优化；五个板块的具体名称尚未在本轮给出，不推定为五个新增功能页面。
- 当前 UI 过于简略，上次优化后提升感不明显；本轮要求先给几个模板，用于选择方向。
- 已查阅 studio-ui.css、studio-ui.js、index.html、storyboard.html 及 2026-10-23 共享助手和整合足迹。已知现有主阶段为编剧、分镜、剪辑，左侧助手 / 右侧工作区及浅绿风格来自前次用户决定。
- AI 分析：当前改善应优先处理工作区主次关系、媒体展示和镜头操作路径；此判断来自源码与记录，尚未对当前运行页面完成真实浏览器审计。

## 本轮方案（未选定、未接入生产）
- 制作工作台：保留浅绿与左侧助手，增加常驻镜头列表、单镜主画面及紧凑参数；适合作为全局基础。

- 导演审片台：深色大画面、右侧参数及下方镜头序列；适合素材检查与剪辑工作场景。
