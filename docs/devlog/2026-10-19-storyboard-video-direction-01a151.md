## AI 建议，尚非用户决定

推荐分阶段的人机协作制作流程：固定剧本版本 → 场戏拆解与资产确认 → 结构化镜头 → 参考图/关键帧 → 人工确认 → 异步视频任务 → 拼接导出 → 按镜头修改及复用。

优先完成可编辑分镜和最小资产引用，再选择单一图像/视频供应商完成少量真实镜头。对比方案包括先直连文生视频（闭环快但一致性和复用弱），以及完整画布/多 Agent 平台（范围大，推迟验证）。

镜头应绑定来源段落、资产版本、画面动作、景别/机位/运动、时长、声音与连续性状态；图像提示词与视频运动提示词分开。可选首尾帧、参考图数量与时长范围遵循选定供应商真实能力，不能预设全部支持。

LangGraph 负责拆解、规划、审核及人工暂停；业务服务负责版本、引用与批准；持久化 worker 负责提交、查询和下载；FFmpeg 负责拼接等确定性处理。保存外部任务 ID，提交结果未知时核对任务，不能直接重提付费请求。

初步验收建议沿用项目计划中的 20～30 秒、3～5 镜头、一种画幅和一家视频供应商；验证完整成片、局部重做、已知任务恢复与未知结果处理。真实角色一致性与成片质量需另做人工评估。
