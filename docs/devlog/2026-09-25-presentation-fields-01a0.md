# 技术字段与用户展示分离

需求：用户发现 draft、original_story 等技术字段出现在呈现内容中。

定位：固定标题已中文化，但审核说明、错误、状态和来源兜底存在直接显示后端值的路径。

实现：新增 presentation.js 集中转换已知字段，普通/流式接口统一输入校验提示；未知状态、来源和阶段采用中文兜底。错误原文仍在明确标记的技术详情内，便于排障。原稿、剧本、引用和接口数据不转换，避免修改用户内容。动态模型文案只转换已知字段，不保证任意英文文案的全文翻译。

验证：使用 Node 测试完整字段边界、嵌套校验路径、未知字段与状态兜底；执行 JS 语法检查。未调用真实模型，未运行数据库全量测试。修改尚未提交；保留其他任务的现有文件修改。
