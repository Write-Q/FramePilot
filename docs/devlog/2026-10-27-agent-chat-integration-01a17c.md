# Agent 对话样式正式接入

## 用户授权与实施范围
- 用户审阅柔和工作室与 Agent 对话预览后表示“可以先尝试一次”；本轮将其接入现有编剧/分镜/剪辑共用助手组件，供真实工作台试用。
- 用户选定 Craft 色彩/画面气质和 FLORA/Linear 工具质感；禁止为 UI 额外生成配图，真实项目素材沿用现有数据。
- 在当前已确认的 codex/database-foundation 分支原位修改；起始 tracked 文件无修改，保留现有 .impeccable、教学记录等其他任务未跟踪文件。不新增 worktree、不清理、不合并 main。
- 不更改会话/API/账本/模型调用逻辑，保留真实模型与思考等级、引用选区、项目隔离、幂等恢复、脏状态拦截和人工确认。

## 实施计划
1. 先运行现有共享助手浏览器回归，补充长消息自动增高/清空复位和窄屏操作可见性检查，确认新增行为的失败证据。
2. 调整共享助手 DOM：状态与恢复提示置于输入框外，输入、模型控制和引用/发送工具分层；消息采用用户气泡和助手正文，提案保留明确预览与执行操作。
3. 统一共享 shell 的浅蓝/奶油白与淡紫选中态，适配三个实际工作区的公共色彩；保留原节点、监听、宽度偏好与移动面板。
4. 定向回归、实际三页宽/窄屏视觉检查，独立代码复核后只提交当前任务文件并推送，核对远程 SHA。

- 不调用真实付费模型进行 UI 测试；浏览器替身/API fixture 与真实后端证据分别记录。
- 阶段检查时额度约剩 43%/86%，没有触及提醒阈值；没有购买或兑换额度。
