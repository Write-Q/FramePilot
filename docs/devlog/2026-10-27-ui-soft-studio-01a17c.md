# 柔和创作工作室 UI 试作

## 已授权方向与纠正
- 用户确认“先按照这个试一试”：Craft 色彩/画面表现，FLORA 和 Linear 质感；本轮按此前约定试做完整分镜页面设计预览，未据此改写生产工作流。
- 用户随后询问图片依据，指出不需要为 UI 再生图。此前图像实际来自助手为概念预览构造的机器人/花朵示例，未绑定真实项目剧本，旧画廊缩略图还是同图裁切。
- 本轮已在收到问题前发起一张四格演示图生成；尝试停止等待时生成已结束。该图不接入预览，不作为项目素材，不追加生成请求；没有调用项目图片生成 API。原图保留于本聊天 generated_images，未覆盖或删除。
- 后续约束：优先复用实际项目已有图片；无已核对素材时呈现真实空状态，不能让用户误认为任意示例图是正式剧本配图。

## 实际改动
- 新建本聊天可视化目录下 `framepilot-soft-studio.html`，独立于生产 app/static。
- 浅天蓝与奶油白底、少量淡紫和柔黄、纸面编辑区、细边界、紧凑工具栏。保留左侧连续讨论，右侧镜头设定和序列。
- 所有媒体区域显示“尚未选用首帧”等空状态，不嵌入图片；示例文字明确标记未绑定项目。
- 本地演示包含镜头切换、专注/总览切换、首/关键/尾帧切换、修改建议对照、草稿保存、未保存切镜拦截、确认和发送状态；无任何项目 API/模型调用。
- 窄屏采用“工作区/创作助手”切换并保留 DOM 草稿；专注编辑时通过上一镜/下一镜切镜，镜头总览单独展开序列，避免整页堆叠助手和长列表。
- 起始账户共享额度：5 小时窗口约剩 78%，周窗口约剩 91%。

## 素材核对与验证边界
- 源码默认素材目录为 data/media；工作区未找到该正式素材目录及正式项目图片，仅发现 data/test-tmp-* 下的测试图像。
- 未读取密钥；未建立真实项目与媒体记录的数据库关联。Docker 只读容器枚举受管道权限限制，不能据此判定用户已有配图不存在。
- 不将本地未发现正式素材表述为用户从未生成素材。
- 最终验证：脚本语法通过；1024/736/390/320 四宽度均无横向溢出，页面图片节点数均为 0；十组本地交互通过，浏览器 pageerror 为 0。检查覆盖镜头切换、未保存拦截、保存后恢复、帧/提示词上下文、建议对照与采用、未保存确认拦截、确认反馈、安全文本消息、专注/总览、手机面板切换与草稿保留。
- 已查看最终桌面与手机截图，手机端改用面板切换后内容无整页堆叠。图标是宿主提供的 Lucide 控件标记，不是新增生成图片；核心交互不依赖图标远端资源加载。
- 首次交互检查发现可视化 sandbox 不允许原生表单提交，保存按钮 click 存在而 submit 未发生；改为原生 button 的显式本地保存事件，继续使用表单约束验证。验证脚本曾因包装器高度预期多计 16px、图标初始化等待超时及中断后浏览器连接失效而未完成；改为实际高度与独立临时浏览器后最终检查通过，不将这些失败算作通过证据。
- 独立预览归档为 `docs/design/ui-soft-studio-2026-10-27-01a17c.html`；说明与验证结果同目录同前缀保存。没有修改 app/static，没有接入真实项目、图片、模型或数据库。草稿仅保留在当前预览 DOM/内存，重载后重置。
- 待完成：用户评价本轮融合风格；确认后再讨论真实页面适配。尚未做生产实现与真实业务验收。
