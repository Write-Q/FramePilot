# 用户展示补全与导出交接文档

需求：补齐审核预览、历史决策、无障碍标签、错误提示及导出文件的中文转换。

实现：前端只转换审核说明与 AI 采用建议，保留用户反馈、替代方案、剧本与引用原文。常见密钥、格式及连接错误采用可操作提示。新增独立 Python 导出呈现层，替换原 JSON 为中文问题、依据、关联卡片和决策记录，状态与未知枚举均有中文兜底。技术详情仍保留原始错误。

验证：Node 展示单元测试、Python 纯导出单元测试及 JS/Python 语法检查；不使用真实模型，不依赖数据库。未执行真实浏览器端到端或数据库全量测试。待应用重启加载后端新导出逻辑。保留其他任务修改；未提交和推送。
