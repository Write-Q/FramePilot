# FramePilot 剧本交接

审核版本：3；当前版本：3；状态：已确认

## 当前剧本

1.（0—7秒）雨后自家院子，湿土上有一株被泥水压弯的幼苗。小禾蹲下，伸手轻轻托住幼苗茎部，把它扶向直立。

2.（7—15秒）小禾找来一根细枝插进幼苗旁的湿土，又拿起旧布条，把幼苗和细枝松松绑在一起。手一松，支架滑落，幼苗又歪倒。小禾皱眉，重新把细枝插深。小禾用指尖轻轻拢紧幼苗根部的湿土。

3.（15—24秒）小禾蹲在原地，反复调整旧布条的绑法：先绕一圈，再拉紧，又松开重来。动作从急促变慢，手指一点点把布条压稳。支架不再滑动，幼苗在湿土里立直。

4.（24—30秒）小禾退后一步，看着立直的幼苗。暖光落在叶尖，湿土泛着微光，小禾安静地站着。

## 最初输入

雨后的小支架

## 用户要求

30秒写实短片；唯一人物小禾，唯一地点自家院子；主线是扶正幼苗；无对白、无画外音、无魔法，不增加新人物或第二地点；结尾温暖。剧本按4个编号镜头段落输出，每段含大致秒数和可见动作，合计30秒。不要另列片名、创作说明或备选结尾。
