# 文字分镜真实模型评测

2026-10-20。结论：**分镜可以用于人工编辑草案，独立审核尚不适合当作自动放行或自动改稿依据。** 本轮修复1处真实拦截缺陷，也确认了审核噪声和高思考截断风险。

## 实际范围

- 实际账户GET/models列出deepseek-flash（DeepSeek-V4.1-Flash）与deepseek-v4-pro，支持low/high/max；本轮只调用Flash。旧环境deepseek-chat未列入目录，本轮未修改.env或业务配置。
- 固定planner1.1.0、reviewer1.0.0；生成low，审核high。max_tokens=16000，timeout=180秒，无自动重试或模型降级。API别名未返回底层快照名，不能把这次结果当永不变化的模型版本保证。
- 9个短合成案例、9次生成+7次审核=16次Chat调用；真实HTTP适配和随机PostgreSQL测试库。Writer只用夹具建立来源/确认，不属于真实编剧评测；不是网页点击真实模型验收。
- 结论由本任务AI逐项对照预设expected/reject判读，未经用户/影视专家盲审；没有图像/视频、真实语音或三维预演，不能证明画面效果或实际运镜成立。

## 生成结果

9/9首次生成通过结构、固定镜头数和来源引用校验；这不等于9/9专业质量完全合格。

| 案例 | 实际观察 | 判读 |
| --- | --- | --- |
| SR001 钥匙交接 | 递出→接住→离开；钥匙归属保持，首帧不提前完成 | 核心预期满足 |
| SR002 长对白 | 原话顺序保留，说话者始终为林；禾点头无台词 | 核心预期满足；首帧与节拍起点可再对齐 |
| SR003 已成立仰望 | 首帧已仰望，车票及右侧指示牌保留 | 核心预期满足 |
| SR004 全景缓推 | 全景首帧/面部近景尾帧分开；但建议面朝门又将门作身后锚点 | 部分满足，空间关系需修正 |
| SR005 无声短信 | 短信原文、屏幕载体、无对白/VO/配乐保留 | 部分满足；角色列表疑将“禾默默看着”的副词并入姓名“禾默默” |
| SR006 数量不足 | 3场全部留存，1镜只规划首场，显式列未分配场并建议至少3镜 | 正确暴露不可行请求；不是全片完整可制作 |

## 审核结果与失败

7次审核的原始业务记录为5成功、2失败。成功只表示结构与证据可接受，不等于其问题和建议全部正确。

- **有用发现**：SR004检出门/朝向/面部近景的空间疑点；SR006发现未覆盖场次并建议调整镜头数；SR007正确指出原稿自身钥匙归属矛盾，要求退回编剧，不允许分镜静默补事件；SR009以不确定语气指出镜门方位需预演。
- **噪声/误报倾向**：多次重复要求确认分镜已经声明待定的地点、灯光/外观；SR001把动作节拍小于全镜时长的余量列为待修问题；SR006也重复要求注明1000ms尾停顿。当前契约只限制节拍和不得超过镜头，不要求精确相等。SR002“开口起幅”的建议应作为轻微对齐讨论，不应自动视为确定错误。
- **建议本身也需审查**：SR004给出的一个备选方案会将剧本明确要求的面部近景改为侧后/过肩落幅，不宜自动采用。
- **失败1（SR001）**：模型引用真实action_beats.N.duration_ms，但校验器漏了该数值字段，整份报告被拒。补回归先复现失败，再最小修复字段白名单，null仍拒。原失败不覆盖；同一最终JSON修复后离线校验通过，未再调用模型。详见[失败分析](canary-failure-analysis.json)。
- **失败2（SR005）**：finish_reason=length，16000 completion_tokens全部为reasoning_tokens，最终content为空。系统正确失败，未冒充空问题通过；本例无法评估审核有没有发现人名问题。

## 用量、耗时和停止边界

服务返回：输入63416、输出105125、合计168541 tokens；请求耗时合计525.299秒，生成中位数23.781秒、审核中位数39.422秒。输出用量包含推理token；未保存原始推理文本。没有拿token换算实际费用，账单/余额未知。

本轮设定“累计返回token超过160000后停止后续”，最后一次返回后越过阈值，因此停止在16次，未继续到20次请求上限。**两条植入错误的阳性对照、同一输入low/high生成对照未运行。** 不报告完整检出率、误报率或档位优劣，不假设高档一定更好；不能据不同任务的低/高耗时直接比较档位。

## 改动、验证与后续

仅产品改动：review_prompt.py支持合法节拍时长证据，并新增回归。相关审核契约/API回归21 passed、0 skipped、1既有Starlette弃用警告；无新增迁移。运行过程中未改提示词，不将修改后的输出混入原基线。

下一步优先：审核规则明确区分已披露的制作假设、允许的表演余量与真实剧情错误；低档审核及阳性对照另做小批验证后再决定默认档位/预算。人物身份应与正式角色资产对齐。完成这些收尾后可继续参考图/首帧，当前结果不支持直接全自动出片。
