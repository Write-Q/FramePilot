# FramePilot 剧本交接

审核版本：3；当前版本：3；状态：已确认

## 当前剧本

镜头1（0-5秒）：写实厨房，晨光从窗户照进来。阿朵站在灶台前，把一颗蛋放进小锅，拧开水龙头接水。她拿起灶台边的老式双铃闹钟，拧动背面旋钮到三分钟刻度，把闹钟放在锅旁，双手撑台盯着锅，等它响。

镜头2（5-10秒）：锅里水开始咕嘟冒泡。阿朵揭一下锅盖看蛋，又盖上；伸手把灶火调小，再调大。她转头看闹钟，指针慢吞吞走，她皱眉，把闹钟挪到灶台边更近处，俯身盯着表盘。阿朵停下动作，短暂屏住呼吸。

镜头3（10-15秒）：阿朵又揭锅盖，热气扑脸，她扇了扇。她拿起闹钟贴到耳边听，晃两下，放回灶台，对着闹钟比划三根手指，又指指锅，越忙越乱，围裙上溅了水点。

镜头4（15-20秒）：闹钟突然大响。阿朵吓得一抖，一把抓起闹钟按下顶部按钮，同时另一只手揭开锅盖——蛋在沸水里已经煮老，蛋白发硬。她愣住，低头看看闹钟，把它塞进围裙口袋，转身从台面上拿起一颗新蛋。

## 最初输入

厨房的倒计时

## 用户要求

20秒写实喜剧；唯一人物阿朵，唯一地点是家里厨房；冲突来自误会闹钟的用途，结尾用一个可见动作完成反转。无对白、无画外音、无魔法，不新增人物或第二地点。按4个编号镜头段落输出，每段5秒，不额外列片名或创作说明。

## 未解决问题

### 问题 1：创作建议

结尾反转的喜剧逻辑偏弱：闹钟被拧到三分钟刻度，却在15-20秒段落才响，与“三分钟计时”的设定在时间上对不上，观众容易把“闹钟不响”理解为坏掉而非用途误会，反转的因果不够清晰。

修改建议：在可见动作层面强化“用途误会”：例如让阿朵拧旋钮时只拧了响铃指针而没按下计时启动，或用她反复确认表盘、拍打闹钟的动作暗示她以为它会自动计时；结尾响铃时用她恍然看表盘的反应点明这是起床闹铃，而非计时到点。

关联卡片：剧情、道具、动作与表演、节奏与规格
