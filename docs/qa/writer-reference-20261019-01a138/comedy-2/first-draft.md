镜头1（0-5秒）：写实厨房，午后侧光。阿朵把一只老式双铃闹钟放到灶台边，旋钮拧到刻度，按下顶部按钮，闹钟“咔哒”一声。她转身背对镜头，抓起案板上的菜快速切配，油锅开始冒细烟。

镜头2（5-10秒）：闹钟突然提前响起，铃声刺耳。阿朵肩膀一抖，猛地回头，视线在闹钟和冒烟的锅之间来回。她冲过去掀开锅盖，白汽腾起，她伸手关掉灶火，又抓起抹布朝锅上方猛扇，动作越来越急，肩膀起伏。

镜头3（10-15秒）：阿朵一把抓起闹钟，手指去按停止键，动作却停住——她低头看见指针停在某个刻度上。她愣了一瞬，随即转身，把闹钟塞进烤箱旁墙上的定时插座里，插头“咔”地卡入。

镜头4（15-20秒）：阿朵退后半步，看着插座上的闹钟。烤箱内部的灯随之熄灭，红色指示灯暗下。她轻轻呼出一口气，抬手把散落的头发别到耳后，厨房恢复安静。
