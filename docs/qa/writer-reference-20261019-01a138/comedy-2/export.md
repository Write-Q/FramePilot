# FramePilot 剧本交接

审核版本：3；当前版本：3；状态：已确认

## 当前剧本

镜头1（0-5秒）：写实厨房，午后侧光。阿朵把一只老式双铃闹钟放到灶台边，旋钮拧到刻度，按下顶部按钮，闹钟“咔哒”一声。她转身背对镜头，抓起案板上的菜快速切配，油锅开始冒细烟。

镜头2（5-10秒）：闹钟突然提前响起，铃声刺耳。阿朵肩膀一抖，猛地回头，视线在闹钟和冒烟的锅之间来回。她冲过去掀开锅盖，白汽腾起，她伸手关掉灶火，又抓起抹布朝锅上方猛扇，动作越来越急，肩膀起伏。阿朵停下动作，短暂屏住呼吸。

镜头3（10-15秒）：阿朵一把抓起闹钟，手指去按停止键，动作却停住——她低头看见指针停在某个刻度上。她愣了一瞬，随即转身，把闹钟塞进烤箱旁墙上的定时插座里，插头“咔”地卡入。

镜头4（15-20秒）：阿朵退后半步，看着插座上的闹钟。烤箱内部的灯随之熄灭，红色指示灯暗下。她轻轻呼出一口气，抬手把散落的头发别到耳后，厨房恢复安静。

## 最初输入

厨房的倒计时

## 用户要求

20秒写实喜剧；唯一人物阿朵，唯一地点是家里厨房；冲突来自误会闹钟的用途，结尾用一个可见动作完成反转。无对白、无画外音、无魔法，不新增人物或第二地点。按4个编号镜头段落输出，每段5秒，不额外列片名或创作说明。

## 未解决问题

### 问题 1：连续性待核对

闹钟在镜头1被放到灶台边并按下顶部按钮，镜头3却被“塞进烤箱旁墙上的定时插座里，插头‘咔’地卡入”。老式双铃闹钟本身没有插头，前文也未交代它带插头或原本连在插座上，反转动作的道具形态前后不连续。

修改建议：在镜头1交代闹钟连着一根线或原本就插在烤箱旁的定时插座上，或把镜头3动作改为把闹钟放回/挂回插座旁并拨动开关，使“插头卡入”与道具形态一致。

### 问题 2：信息待补充

反转依赖“闹钟只是提醒关烤箱的旧习惯”，但当前稿只呈现她把闹钟塞进插座、烤箱灯灭，没有可见细节表明这是她惯常的关烤箱提醒动作，观众难以从画面读出“旧习惯”而非临时起意。

修改建议：在镜头1或镜头3加入一个可见的旧习惯痕迹，例如插座旁已有被磨亮的插孔、闹钟背面贴着“关烤箱”的旧标签，或她插回时顺手把烤箱旋钮归位，让反转靠画面成立。

### 问题 3：创作建议

镜头2中“视线在闹钟和冒烟的锅之间来回”已经暗示她意识到两者关联，但随后仍完整演出掀锅、关火、扇烟，误会链条偏向直接反应，喜剧节奏的“误判”层次略弱。

修改建议：保留慌乱动作，但让她的视线先锁定闹钟、再误读为菜要糊，用一个短促的误判反应（如先冲向锅而非闹钟）强化误会，不增加对白或人物。
