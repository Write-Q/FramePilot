# 视频审核第一版验收

对象为本阶段工作区。视频由本地PyAV真实编码，供应商为替身；没有调用付费生成或视觉模型。

- 技术证据：受控子进程实际解码并采样JPEG，保存时间戳、原视频checksum、分镜版本和计划/实际差异。短片不足请求帧数不补造图像。
- 记录：报告/人工结论追加保存，错误时间区间拒绝，项目/视频/报告相互归属校验；改稿、文件损坏及采样中版本变化不能继续写当前结论。
- 并发：同幂等请求只落一报告，未引用的新帧被清理；响应丢失后保留原意图恢复，不自动新建请求。
- 网页：完整Edge页面实际播放、检查视频、读取真实帧图片、保存人工结论，并断言审核没有自动选用视频；界面mock覆盖旧版本、脏稿、恢复等边界。

复核发现的两项P2已修复：technical.actual/planned嵌套映射与界面不一致；备注4000字上限与接口2000字不一致。界面改为正确字段、中文偏差提醒、实际时长上限及2000字限制，四项界面回归通过。

前期定向15项通过；后端新增并发/HTTP/不可变保护后与视频运行时合计26项通过。完整回归结果以本目录pytest.xml与收尾记录为准，不合并不同批次计数。

边界：稀疏帧不覆盖所有瞬间；尚无自动人物、口型、台词、声音或剧情审核。测试主要是固定帧率H264短片，不构成长视频、WebM/VFR/音视频起始偏移的完整验收，也未验证真实模型效果。

最终完整回归369 passed/0 skipped/0 failed/0 errors，200.96秒，1既有Starlette/AnyIO弃用提示。四项浏览器mock另行通过。通过范围是当前工程与人工审核流程，不是模型语义质量。
