1. 约0—7秒：书桌旁，小宁的双手把旧书放到桌面中央。镜头贴近桌面，可见封面卷边、页角折损。小宁用一只手掌从封面中间向边缘缓缓推压，一点点抚平卷边；呼吸平稳，手指在折损页角处停住，轻轻压平。

2. 约7—15秒：小宁拿起新书皮，沿桌边裁好，再把书皮摊开，双手对齐书脊，将旧书放上去，从书脊一侧慢慢包合。手掌沿封面压过，书皮边缘逐渐贴合。

3. 约15—23秒：包到一半，小宁的手停住。书皮一侧比旧书边缘略短。小宁低头重新比对旧书边缘，手指沿书皮短边量过，随后把已包上的书皮拆下，重新裁去多余部分，再对齐书脊包上。呼吸在停顿处变轻，动作放慢。

4. 约23—30秒：小宁把包好的书在桌面上放正，双手离开，指尖轻压封面中央，沿边缘抚过一次。小宁看着封面，露出满意微笑。画面停在小宁的手与包好的旧书上，温暖收束。
